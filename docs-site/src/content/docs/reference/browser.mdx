Install or remove the Browser app (Chromium's headless shell)

### `aos browser install`

Download and install the Browser (run with sudo)

```
aos browser install [flags]
```

Options:

```
      --no-deps   don't apt-get the system libraries the browser needs; just report any that are missing
```

### `aos browser remove`

Remove the installed Browser (run with sudo)

```
aos browser remove
```
