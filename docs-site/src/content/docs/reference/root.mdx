Show or switch Root Mode (on or off)

```
aos root [on|off]
```

### `aos root off`

Turn off Root Mode: leave the Root Realm and restart into Standard Mode

```
aos root off [flags]
```

Options:

```
      --yes   skip the confirmation (for scripts); it does not override the running-Agent check
```

### `aos root on`

Turn on Root Mode: Agents and the Terminal run as root; AOS restarts

```
aos root on [flags]
```

Options:

```
      --yes   skip the confirmation (for scripts); it does not override the running-Agent check
```
