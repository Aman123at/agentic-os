Show or switch the Machine's Mode (ui or cli)

```
aos mode [ui|cli]
```

### `aos mode cli`

Switch off the Desktop: write mode: cli and restart (control socket only)

```
aos mode cli
```

### `aos mode ui`

Switch on the Desktop: create the account if needed, write mode: ui and restart

```
aos mode ui [flags]
```

Options:

```
      --user string   the username to sign in with (default "admin")
```
