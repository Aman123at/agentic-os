<h2 class="aos-section-title">Install in one line</h2>
<p class="aos-section-lead">Pick the way that fits your device. Every path ends at the same Desktop.</p>

<Tabs syncKey="install">
  <TabItem label="Linux server" icon="linux">
    On Ubuntu 22.04+ or Debian 12+, with `sudo`. You don't need Go, Node, Docker or an API key to install.

    ```bash
    curl -fsSL https://raw.githubusercontent.com/Aman123at/agentic-os/main/install.sh | sudo sh
    ```

    Then open `http://<your-server-ip>:7700`. [Full server guide →](/start/install/)
  </TabItem>
  <TabItem label="macOS" icon="apple">
    Runs inside Docker Desktop. The Agents only see the container, never your Mac.

    ```bash
    git clone https://github.com/Aman123at/agentic-os.git ~/src/agentic-os
    cd ~/src/agentic-os && cp .env.example .env
    docker compose up -d --build
    ```

    [Step-by-step for macOS →](/start/macos/)
  </TabItem>
  <TabItem label="Windows" icon="seti:windows">
    Runs inside Docker Desktop with the WSL 2 backend.

    ```powershell
    git clone https://github.com/Aman123at/agentic-os.git
    cd agentic-os; copy .env.example .env
    docker compose up -d --build
    ```

    [Step-by-step for Windows →](/start/windows/)
  </TabItem>
  <TabItem label="Raspberry Pi" icon="laptop">
    A 64-bit Raspberry Pi OS or Ubuntu Server on a Pi 4 or Pi 5 uses the native installer.

    ```bash
    curl -fsSL https://raw.githubusercontent.com/Aman123at/agentic-os/main/install.sh | sudo sh
    ```

    [Raspberry Pi & ARM guide →](/start/raspberry-pi/)
  </TabItem>
</Tabs>

<h2 class="aos-section-title">Everything an operator needs</h2>
<p class="aos-section-lead">A full desktop and a real command line, built around one idea: the Agents do the work, and you stay in charge.</p>

<CardGrid>
  <Card title="Tasks in plain English" icon="pencil">
    "Set up Postgres with a nightly backup." "Read these CSVs and build me a report." An Agent plans the work,
    runs real commands and shows every step live.
  </Card>
  <Card title="A Desktop in your browser" icon="laptop">
    Menu bar, Dock, windows and Spotlight search, plus Finder, Terminal, TextEdit, Preview, Activity Monitor and
    System Settings. Light and dark themes.
  </Card>
  <Card title="Approvals before anything risky" icon="approve-check">
    Autonomy levels, Protected Paths enforced by the kernel (Landlock), a Trash instead of `rm`, and an
    append-only Audit Log of everything that happened.
  </Card>
  <Card title="Undo for software" icon="random">
    Every package an Agent installs lands in the Install Ledger. Take a Checkpoint and restore the machine's
    software to it later.
  </Card>
  <Card title="Services that stay up" icon="rocket">
    Agents can start long-running Services that survive restarts. Open any of them in your browser from the
    Desktop, behind your password.
  </Card>
  <Card title="Terminal-first when you want it" icon="seti:shell">
    Everything the Desktop does, `aos` does over SSH: chat, one-shot `aos run`, approvals, logs, config and
    more.
  </Card>
</CardGrid>
