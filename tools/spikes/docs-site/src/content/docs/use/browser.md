STUB — page map only. This page exists so the sidebar and the shape of the site are
judgeable; M6 writes it.

Must carry: `sudo aos browser install`, which downloads about 120 MB and needs about 1 GB free;
the distributions Chrome for Testing publishes for — ubuntu22.04, ubuntu24.04, ubuntu26.04,
debian12, debian13, and **not** ubuntu18.04 or ubuntu20.04; that Compose users run the same
command, because the published image no longer carries Chromium; and `sudo aos browser remove`.
