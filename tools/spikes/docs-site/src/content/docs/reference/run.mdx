Run one Task and wait for it (for scripts: without a terminal, calls that need an Approval are denied)

```
aos run "<task>" [flags]
```

Options:

```
      --autonomy string   auto, confirm-risky or confirm-all for this Task (default: the configured Autonomy)
      --json              print events and the final Task as JSON lines
```
