List, restore or empty the Trash

### `aos trash empty`

Delete everything in the Trash permanently

```
aos trash empty [flags]
```

Options:

```
      --yes   confirm
```

### `aos trash list`

List the Trash

```
aos trash list
```

### `aos trash restore`

Put an item back

```
aos trash restore <id>
```
