Software installed through AOS: the Install Ledger

### `aos software ledger`

Every recorded change with root authority, newest first

```
aos software ledger [flags]
```

Options:

```
      --limit int   how many operations (default 20)
```

### `aos software list`

Software the Machine gets back after every restart

```
aos software list [flags]
```

Options:

```
      --all   include dependencies
```
