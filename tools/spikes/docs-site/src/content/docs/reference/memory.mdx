Memory: what every Agent is told about your preferences

### `aos memory accept`

Accept an Agent's proposal

```
aos memory accept <id>
```

### `aos memory add`

Remember something for every future Task

```
aos memory add "<text>"
```

### `aos memory forget`

Remove an entry or reject a proposal

```
aos memory forget <id>
```

### `aos memory list`

List Memory and the Agents' proposals

```
aos memory list
```
