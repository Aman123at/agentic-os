List, create or restore Checkpoints of the Machine's software

### `aos checkpoint create`

Name the current state

```
aos checkpoint create ["<name>"]
```

### `aos checkpoint list`

List Checkpoints, newest first

```
aos checkpoint list
```

### `aos checkpoint restore`

Undo every software, /etc and Service change since a Checkpoint

```
aos checkpoint restore <id>
```
